# E2E-тесты

Владелец: `qa-ui`.

Правила:

- сценарии независимы и начинаются с чистого состояния;
- проверяется пользовательский результат, доступность и мобильность;
- доказательства (скриншоты, trace, консоль, сеть) сохраняются в отчёте;
- production-код здесь не меняется;
- найденные баги передаются Рефактореру, а не исправляются в тестах.

Предпочтительный раннер — Playwright (`@playwright/test`).
