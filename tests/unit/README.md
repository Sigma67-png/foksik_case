# Unit-тесты

Владелец: `unit-test-generator`.

Правила:

- тесты детерминированы, без сети, реальной MongoDB и системного времени;
- тестируется поведение, а не реализация;
- production-код здесь не меняется;
- если код не тестируется без рефакторинга, пишется `factory/artifacts/05-unit-tests/refactor-request.md`.

Команда запуска появится после выбора раннера. Предпочтение — встроенный `node:test`.
