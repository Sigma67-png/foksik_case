# Журнал запусков

Владелец: `factory-lead`.

Здесь главный агент может хранить краткие журналы запусков конвейера:

- какой субагент запускался;
- с какой задачей и входными файлами;
- какой handoff получен;
- какие gate пройдены или возвращены на доработку;
- какие решения принял пользователь.

Формат — один Markdown-файл на запуск: `YYYY-MM-DD-<stage>.md`. Секреты и персональные данные сюда не попадают.
