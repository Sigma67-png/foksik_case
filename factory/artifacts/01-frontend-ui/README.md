# 01 — Фронтенд и UI

**Владелец:** `frontend-ui`.

Ожидаемые файлы:

- `ui-spec.md` — разбор макетов, экраны, состояния, DOM-ориентиры.
- `implementation-notes.md` — что изменено, какие классы/ID/события добавлены.
- `handoff.md` — контракт передачи `logic-state` и `qa-universal`.

Код меняется в `index.html`, `*.html`, `css/**`, `assets/**`, `js/ui/**`. `js/main.js`, бэкенд, тесты и docs не трогаются.
