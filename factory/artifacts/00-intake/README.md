# 00 — Вход, архитектура и декомпозиция

**Владелец:** `factory-lead`.

Здесь главный агент фиксирует постановку задачи, проектирует архитектуру, контракты и разбивает работу на атомарные подзадачи для четырёх субагентов.

Ожидаемые файлы:

- `task.md` — постановка задачи и критерии готовности.
- `constraints.md` — границы, запреты и допущения.
- `architecture.md` — границы локального/серверного состояния, компоненты, потоки данных.
- `contracts.md` — UI-контракт и API-контракт.
- `decomposition.md` — атомарные подзадачи с владельцами и критериями приёмки.
- `file-ownership.md` — кто какие файлы может менять.

Без `architecture.md`, `contracts.md` и `decomposition.md` программисты не запускаются.
