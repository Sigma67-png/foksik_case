# 04 — QA, тесты и документация

**Владелец:** `qa-universal`.

Ожидаемые файлы:

- `test-plan.md` — матрица «риск → тест».
- `qa-report.md` — результаты, доказательства, баги по severity.
- `bugs.md` — шаги, ожидаемо/фактически, evidence.
- `fixes.md` — что исправлено и почему.
- `documentation-report.md` — что обновлено в README/docs.
- `handoff.md` — итоговый контракт готовности.

Тесты лежат в `tests/**`, документация — в `README.md` и `docs/**`. QA может исправлять мелкие дефекты в коде, но не переписывает архитектуру.
