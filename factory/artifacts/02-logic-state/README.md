# 02 — Логика и стейт-менеджмент

**Владелец:** `logic-state`.

Ожидаемые файлы:

- `state-model.md` — сущности, инварианты, миграция `localStorage`.
- `integration-notes.md` — API-клиент, демо-авторизация, фильтры, события.
- `handoff.md` — контракт передачи `qa-universal`.

Код меняется в `js/main.js`, `js/state/**`, `js/api/**`, `js/data/**`, `js/auth/**`. HTML, CSS, `js/ui/**`, бэкенд, тесты и docs не трогаются.
