# Инструменты и окружение

Проект работает без внешних плагинов и MCP-подключений. `AGENTS.md` и документы `docs/` — основные инструкции; инструменты могут ускорить работу, но не выбирают стек и не заменяют решения по ТЗ.

## Навыки

Перенесённые Superpowers-навыки лежат в `.agents/skills/`. OpenCode автоматически ищет навыки в `.agents/skills` (совместимый путь) и в `.opencode/skills`. Навык загружается инструментом skill по его ID.

Доступные навыки: `using-superpowers`, `brainstorming`, `writing-plans`, `dispatching-parallel-agents`, `subagent-driven-development`, `systematic-debugging`, `receiving-code-review`, `requesting-code-review`, `verification-before-completion`.

Правила: используй навык, если задача ему соответствует; не превращай короткую задачу в церемонию; при конфликте с согласованным объёмом проекта следуй `AGENTS.md` и `docs/`.

## Что доступно в этом окружении

- Терминал, файлы, git.
- Браузерная автоматизация — после появления запускаемого сценария; не заменяет ручную проверку.
- Веб-поиск и загрузка страниц — для исследования; фиксируй дату и источник в `templates/RESEARCH-LOG.md`.
- GitHub CLI — если установлен и авторизован; не обязателен.
- `design-preview` — React/Vite; требует Node.js 24.13+ и pnpm 10.29.3. В текущем окружении Node 26.13 и нет pnpm, поэтому превью не запускалось.

## Ограничения

- Не добавляй MCP-сервер или плагин, если хватает встроенного инструмента, CLI или навыка.
- Покупки, платные компоненты и платная генерация требуют отдельного согласия.
- Не сохраняй токены, ключи и строки подключения в репозитории. Секреты — только через переменные окружения и `.env` (не коммитится).
- Не выдавай локальный запуск за публичный деплой.
- Не устанавливай пакет только из-за популярности: проверь лицензию, совместимость и минимальный объём.
