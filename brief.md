# Исходное ТЗ

## Статус

Оригинальный текст задания в репозитории отсутствует. По состоянию на 2026-11-19 единственные источники вводных — `README.md`, текущий код и `пример.jpg`. Этот файл не заменяет ТЗ: он фиксирует, что известно, и какие вопросы нужно закрыть.

Если у задания есть исходный документ (PDF, DOCX, ссылка, сообщение), добавь его в репозиторий без изменений и укажи путь ниже. Не пересказывай оригинал здесь.

## Известные вводные

- **Проект:** Foksik Case.
- **Продукт:** сайт открытия кейсов CS2.
- **Реализованные функции:** каталог кейсов и фильтры, рулетка открытия, выигрыш с выбором «продать / в инвентарь / ещё раз», инвентарь, продажа предметов, апгрейд, демо-пополнение баланса, демо-батлы, лайв-фид.
- **Стек:** статический фронтенд (HTML/CSS/JS без сборки) + Express/Mongoose API с MongoDB.
- **Бэкенд:** CRUD пользователей; к фронтенду не подключён.
- **Визуальный референс:** `пример.jpg` — мобильный экран апгрейда upgrader.pro.
- **Режим:** демонстрационный прототип. Реальных платежей, авторизации и вывода средств нет.
